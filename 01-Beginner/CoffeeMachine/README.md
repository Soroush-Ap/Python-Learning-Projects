# Coffee Machine OOP

A command-line coffee machine simulation built with Python using Object-Oriented Programming.

## Features

- Choose between espresso, latte, and cappuccino
- Check whether enough ingredients are available
- Process coin payments
- Calculate and return change
- Track machine resources
- Track profit
- Generate resource and money reports
- Turn off the machine using the `off` command
